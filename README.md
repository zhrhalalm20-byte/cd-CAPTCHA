# Nataeji Seat Number Search

واجهة عربية حديثة للاستعلام عن أرقام جلوس الثانوية العامة، مع خادم Node.js ينفذ البحث من خلال جلسة مستقلة إلى صفحة الاستعلام الرسمية.

## الملفات

كل الملفات الأساسية موجودة في المجلد الرئيسي بدون بنية مجلدات متداخلة:

- `index.html` — الواجهة.
- `style.css` — التصميم المتجاوب.
- `app.js` — تفاعل البحث والنتائج والنسخ والطباعة.
- `server.js` — API والربط بالمصدر الرسمي.
- `package.json` — الاعتمادات وأمر التشغيل.
- `logo.png` — الشعار المستخدم.
- `.gitignore` — إعداد Git.

## التشغيل محليًا

```bash
npm install
npm start
```

ثم افتح:

`http://localhost:3000`

## GitHub / Railway / Render / أي خادم Node

- Runtime: Node.js 20+
- Build/Install: `npm install`
- Start: `npm start`
- Port: يقرأ `PORT` من البيئة تلقائيًا.

## نقاط API

- `GET /api/health` — فحص الخادم.
- `GET /api/years` — قائمة الأعوام.
- `POST /api/search` — تنفيذ البحث الحقيقي.

### مثال الطلب

```json
{
  "academic_year": "2025/2026",
  "student_name": "الاسم الأول الاسم الثاني الاسم الثالث الاسم الرابع"
}
```

> ملاحظة: الموقع لا ينتحل صفة الإدارة العامة للاختبارات. البيانات تأتي من المصدر الرسمي عندما يكون متاحًا، والخدمة نفسها عبارة عن واجهة وخادم وسيط.
